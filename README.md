# Human Variables Lab

How should increasingly capable AI systems collaborate with humans?

This repository is a living notebook exploring that question through research notes, experiments, essays, and prototypes.

The work draws on experience in aerospace, autonomous systems, quantum hardware, and AI infrastructure.


## Current Research Questions

- How should AI communicate uncertainty?
- How should humans calibrate trust in increasingly capable AI systems?
- What makes human-AI collaboration effective?
- How should evaluation evolve as reasoning models become more autonomous?


## Philosophy

I believe that the future of AI will depend not only on more capable models, but on designing systems that humans can understand, trust appropriately, and collaborate with effectively.

This repository is a living notebook documenting that exploration.
